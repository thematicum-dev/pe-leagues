# Rohbilder der Kandidatenporträts

Ablage für die Porträts aus dem Briefing (Hochformat 2:3, Original-Download
aus dem Bildgenerator, keine Screenshots). Der Ordner ist eine Zwischenablage:
Beim Einbinden werden die Bilder auf 720 × 1080 verkleinert, als WebP nach
`public/manager/` gelegt und dieser Ordner wieder gelöscht.

- `kandidaten/` — die 64 Porträts für CEO und CFO (`f01`–`f32`, `m01`–`m32`)
- `fachfunktionen/` — die 40 Porträts für die Fachfunktion (`ind-`, `hc-`, `sw-`, `bd-`, `cmo-`)

Dateiname am besten wie die ID, zum Beispiel `f07.png` oder `hc-m2.jpg`.
Andere Namen gehen auch; die Zuordnung wird beim Einbinden geprüft.
